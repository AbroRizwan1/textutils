TextUtils – Text Utility App

TextUtils is a simple and useful React app that helps you quickly analyze and manipulate your text. Whether you want to clean up your content, change its format, or just get quick stats, this tool makes it fast and easy.

✨ Features 🔠 Convert text to Uppercase 🔡 Convert text to Lowercase 🧹 Clear text instantly 📋 Copy text to clipboard ⏱️ Count words and characters 📖 Estimate reading time 🌙 Toggle between Light & Dark mode ⚡ Real-time updates as you type 🧠 Why I Built This

I created this project to practice React fundamentals like state management, handling user input, and building responsive UI. It’s a small project, but it helped me understand how to make interactive applications that respond instantly to user actions.
