# ✍️ TextUtils — Text Utility App

A simple and fast React app to analyze and manipulate text instantly. Clean up content, change formatting, and get quick stats — all in real time.

🔗 [Live Demo](https://abrorizwan1.github.io/textutils) · [GitHub](https://github.com/AbroRizwan1/textutils)

---

## ✨ Features

- 🔠 Convert text to Uppercase / Lowercase
- 🧹 Clear text instantly
- 📋 Copy text to clipboard
- ⏱️ Word count, character count & reading time
- 🌙 Light & Dark mode toggle
- ⚡ Real-time updates as you type

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React.js | UI & state management |
| JavaScript (ES6+) | Logic & interactivity |
| Bootstrap | Styling & responsive design |

---

## 🚀 Getting Started
```bash
git clone https://github.com/AbroRizwan1/textutils.git
cd textutils
npm install
npm start
```
